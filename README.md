# Capstone Project 4 — Use a Public API

A small web project that consumes a public API and demonstrates data fetching, rendering, and basic interactivity.

Live demo (GitHub Pages):

https://gurveersingh8806.github.io/Capstone-Project-4---use-a-public-API/

If GitHub Pages is not yet enabled for this repository, you can test the site locally or using the RawGit/RawGithack preview described below.

Quick start — run locally

1. Clone the repo:

   git clone https://github.com/gurveersingh8806/Capstone-Project-4---use-a-public-API.git

2. Open the project folder and either:
   - Open index.html directly in your browser (double-click), or
   - Serve the files with a simple static server (recommended):

     python3 -m http.server 5500

     Then open http://localhost:5500 in your browser.

Testing without enabling GitHub Pages

- RawGithack (temporary preview):

  Replace <branch> with the repository's default branch (commonly `main` or `master`):

  https://raw.githack.com/gurveersingh8806/Capstone-Project-4---use-a-public-API/<branch>/index.html

Enable GitHub Pages (to make the Live demo link work)

1. Go to the repository on GitHub: https://github.com/gurveersingh8806/Capstone-Project-4---use-a-public-API
2. Settings -> Pages
3. Under "Build and deployment" choose the branch (usually `main`) and the folder (root /) then Save.
4. After a minute the site should be available at the GitHub Pages URL above.
